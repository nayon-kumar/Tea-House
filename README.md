# Tea-House

<p>To show the live preview <a href="https://nayon-kumar.github.io/Tea-House/">Click Here</a></p>

## Overview

A modern and responsive **Tea House Landing Page** built using **HTML and Tailwind CSS**.

## 🛠 Technologies Used

- **HTML5** – Page structure
- **Tailwind CSS (CDN)** – Styling and responsive design
- **Font Awesome** – Icons
- **Google Fonts (Manrope)** – Typography

## 🚀 Features

- Fully responsive landing page
- Modern UI design
- Gradient buttons and backgrounds
- Featured tea products section
- Customer testimonial section
- News & events section
- Newsletter subscription form
- Social media icons
- Smooth hover effects
